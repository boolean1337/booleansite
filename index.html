Какие моды встроены?

В лаунчер вшиты 7 модов:

  • Sodium — оптимизация FPS
  • Iris — шейдеры (совместим с Sodium)
  • Lithium — оптимизация серверной логики
  • PlasmoVoice — голосовой чат
  • Appleskin — отображение насыщения еды
  • Fabric API + Fabric Language Kotlin — основы

При каждом запуске папка mods очищается от левых .jar и синхронизируется с bundled.

Какие ресурспаки?

Два варианта Faithful — 32x и 64x. Применяются через вкладку Resource Packs в лаунчере. Посторонние ресурспаки автоматически удаляются при запуске.

Отслеживание сервера

В топ-баре лаунчера отображается текущий онлайн play.hitvoidsmp.ru (опрос каждые 60 секунд через mcsrvstat.us).

Система комментариев

В разделе Community можно смотреть профили игроков, писать комментарии, ставить репутацию. При первом открытии профиля бот автоматически пишет приветствие.

Авторизация и скины

Встроена Ely.by авторизация (authlib-injector) для скинов в игре. Скин автоматически подтягивается при каждом входе в лаунчер. Кнопка Import from Mojang удалена — всё автоматически.

Поддержка ОС

Только Windows 10/11. Лаунчер использует Windows-specific функции (javaw.exe, APPDATA). Версии для Linux/macOS не планируются.

Java не установлена?

Лаунчер сам скачает JDK 21 с Adoptium при первом запуске. Также можно указать свой путь в Settings > Java Path. Системная Java 21 тоже подхватится автоматически.
